# Mays Owais — Portfolio

**Live site:** https://maysowais.github.io/Mays-s-Portfolio/

My personal portfolio as a Python developer, data analyst and AI & programming trainer.

## Features

- Responsive design for desktop, tablet and mobile
- Dark and light mode (the choice is remembered)
- Sections for experience, training, filterable projects, skills, achievements and certifications
- Contact form that delivers messages straight to my email (via FormSubmit)
- One-click CV download
- Built with plain HTML, CSS and JavaScript, with no frameworks and no build step

## Tech

HTML5 · CSS3 (custom properties, grid, flexbox) · Vanilla JavaScript · GitHub Pages
